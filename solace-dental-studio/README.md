# Solace Dental Studio — AI Booking Agent Demo

A working demo website for a fictional dental clinic in Chicago, built to show how an AI agent handles patient bookings on a clinic website.

## What it does

- The clinic site shows treatments with prices, patient reviews and trust signals.
- The built in AI receptionist, Ava, chats with the patient, answers questions, and completes a real booking flow: pick a treatment, pick a day, pick a time, give a name, and get a booking confirmation card.
- Everything runs in one page with plain HTML, CSS and JavaScript. No build step. Open `index.html` in a browser and it works.

## Files

- `index.html` — the page structure and content
- `style.css` — all design and layout
- `script.js` — the AI receptionist logic: the chat, the booking flow and the confirmation

## Why it exists

Dental clinics lose patients every week because the phone rings while the team is busy and callers book somewhere else. This demo shows the fix: an AI agent on the website that replies in seconds and books the appointment, day or night.
